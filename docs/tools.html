Puri's tools

The model can't open a file or reach the network on its own. Everything it does, it does by calling one of the tools below, and the conversation shows a line for each call, such as "📧 Searched mail". Here is every tool, what it does, what it sends out of your computer, and how to turn it off.

What no tool does

No tool opens a URL, runs a command, or sends a mail or an invite. pikuri, which Puri is built on, has tools that fetch a web page and run commands; Puri doesn't give them to its model. So a mail written to trick the model has no way to send what it reads to whoever wrote it, and everything that does leave goes to a service you set up, listed below and drawn on the front page.

Turning a feature off

Each feature is a table in ~/.config/puri/config.toml, and the tools below come in those same groups. To turn one off, put a # before its table's line and each line under it, quit Puri with Ctrl+Q, and press Super+Alt+Space. Its tools are then gone: the model isn't told of them, and can't call them. A feature is all or nothing; there's no switch for one tool alone. What each feature needs to work, and how to change it, is in the install guide's Each feature.

Mail, contacts and calendar

Read from your Thunderbird profile, snap or apt. Puri searches copies of Thunderbird's mail index and calendar in ~/.cache/puri, and never writes to Thunderbird's own files. The mail and contact tools need Thunderbird's global search; without it, those four are left out.

ToolWhat it doesWhat it sends
thunderbird_mail_search📧 Searched mailFinds mails by what they say, who sent them, to whom, and when.Nothing
thunderbird_mail_read📧 Read a mailReads one mail the search found, and lists its attachments.Nothing
thunderbird_mail_attachment_read📎 Read an attachmentReads an attachment's text. A PDF or an office file is converted in a container with no network when podman is installed; without podman, only a PDF is read.Nothing
thunderbird_contact_search👤 Looked upFinds a person's address among the people you've written to or heard from.Nothing
thunderbird_calendar_search📅 Searched the calendarFinds events by what they say, where they are, and when.Nothing
thunderbird_calendar_read📅 Read an eventReads one event in full, with who's coming.Nothing
thunderbird_mail_compose✉ Draft opened in ThunderbirdOpens a draft in Thunderbird's compose window, in plain text, with a recipient you've never written to flagged. Puri never sends.Nothing, until you click Send in Thunderbird; the mail then goes to its recipients, as any mail of yours does.
thunderbird_calendar_create📅 Event opened in ThunderbirdOpens an event in Thunderbird's import wizard, where you pick the calendar. It has no guests, so it invites nobody.Nothing, until you confirm in Thunderbird; in a calendar on a server, the event then syncs there, as any event of yours does.

Turns off all eight:

[thunderbird]
enabled = false

Documents and notes

Your Documents folder, whatever your desktop's language calls it, or the folder under [documents]. Puri reads all of it, and writes only in its Notes folder inside. What you ask it to remember is a note too: Notes/PURI.md, which the model reads at the start of each conversation.

ToolWhat it doesWhat it sends
fileindex_search🗂 Searched filesFinds files by the words in them, through GNOME's file index, which holds the text of PDFs and office files too.Nothing
fileindex_read📄 ReadReads a file's text as the index holds it.Nothing
read📄 ReadReads a file from the disk, such as a note just written; a PDF or an office file is converted as an attachment is.Nothing
glob🗂 Looked for filesFinds files by their name.Nothing
file_list🗂 ListedLists what's in a folder.Nothing
write📝 WroteWrites a note, inside Notes only.Nothing
edit📝 EditedChanges a note, inside Notes only.Nothing

Turns off all seven, and what Puri remembers with them, since that's a note. Put the # before folder too, if you set one:

# [documents]

Places and routes

From OpenStreetMap's public services, which GNOME Maps asks too, with no key and no account: the only name a request carries is Puri's own, as their terms ask. A tool takes a place in one of three ways. A number from an earlier answer sends nothing. Coordinates go to Nominatim, which names the address there. A name or an address goes to Photon, along with the point of the other place, when there is one, so that "Prisma" is found nearby and not in Bolivia.

ToolWhat it doesWhat it sends
place_search📍 Looked upFinds a place by its name or address, or what's of one kind near a place, such as cafés: each with its distance by car, opening hours and website, on a map. For "near me", it asks your home address once, and remembers it in Notes/PURI.md.First the place it searches near, as above. Then, for a name or an address, that name or address to Photon, and the places found to Nominatim, for their opening hours; for a kind of place, the kind and a box around that point to Nominatim. Last, the points to FOSSGIS's OSRM, for the drive to each.
route🚗 RouteHow far, and how long by car, from one place to another, with the road on a map.Both places, as above; then to FOSSGIS's OSRM, their two points.

The map under an answer is drawn from tiles of the area on screen, which come from the server in tiles under [maps], OpenStreetMap's own unless you change it. A click on a pin opens the place in GNOME Maps, or on openstreetmap.org when Maps isn't installed.

Turns off both. The weather finds its place here, so turn it off too:

# [maps]
# tiles = "https://tile.openstreetmap.org/{z}/{x}/{y}.png"

Music

ToolWhat it doesWhat it sends
play_music🎵 MusicPlays an artist, an album, a song or a genre from your Rhythmbox library, and starts Rhythmbox if it isn't running. It takes names, never a link.Nothing: it talks to Rhythmbox, on this computer.

Web search

Off until you add a key of your own, Brave Search's or Exa's, as the install guide's step 8 does.

ToolWhat it doesWhat it sends
web_search🔍 Searched: "what it searched for"Searches the web, and keeps the engine's copy of each page it found.The search query, which the model writes and may quote your mail, with your key: to Brave, which keeps its log of queries for up to 90 days and says it never trains on them, or to Exa, whose terms let it train on what you search for. With both keys, either one. Exa is asked for its stored copies only, so it doesn't visit a page on Puri's behalf.
web_read_cached📄 Read a page the search foundReads the engine's copy of a page the search found. It takes the label the search gave the page, never a URL, so it can't open a link, nor follow one inside the page.Nothing: the copy came with the search.

Turns off both:

# [search]
# brave_key = "…"
# exa_key   = "…"

Besides the tools

Three more things go somewhere, though the model calls none of them.

  • The model reads the whole conversation: what you ask, what each tool returned, and Notes/PURI.md. It runs in llama-server on this computer, unless the [[server]] it's on has a url: then all of it goes to that server, a home server of yours or a hosted one. Choose a model has the choices.
  • The title of each conversation comes from its first message, which goes to the model under [titler], on the same server unless you change it.
  • Dictation sends your voice, one clip at a time, to Whisper on this computer, unless [dictation] has a url.
