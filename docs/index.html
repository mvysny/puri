Ask your desktop.

Puri is an assistant for GNOME. Press the shortcut, ask, and it answers from your mail, your calendar, your documents and the web. The model runs on your own machine.

It already knows where your things are.

Puri works with what GNOME and Thunderbird already keep on your disk, so there's nothing to import.

Mail and contacts

Finds a mail, sums up a thread, looks up an address. Writes a draft and opens it in Thunderbird for you to send.

Calendar

What's on Thursday, when the dentist is, which day the trip starts. Drafts an event for Thunderbird to add.

Documents

Searches your Documents folder through GNOME's own file index, PDFs and office files included.

Notes and memory

Keeps notes in Documents/Notes, and remembers what you tell it in one plain Markdown file you can edit.

Web search

Brave or Exa, with your own key. Puri reads the search engine's copy of a page and never opens a link itself.

Places and routes

Where a place is, what's open nearby, how far by car, from OpenStreetMap, with a map under the answer.

Weather

Open-Meteo's forecast in GNOME's units, about two weeks ahead, for any place or for the trip in your calendar.

Music

"Play some State Azure." Plays an artist, an album, a song or a genre from your Rhythmbox library.

Dictation

Press F5 and talk. whisper.cpp, on your machine or your home server, types what you said.

Every conversation

Each earlier conversation is one click away in the same window, saved on your disk.

Search, never fetch

Puri talks to the search, map and weather services you set up, and never opens a URL.

Sending is always your click

A mail opens in Thunderbird's compose window, an event in its import wizard.

On this computer or your own server. A hosted model is something you opt into.

What it won't do

Act on its own

No schedules and no errands in the background. Puri answers when you ask, and does nothing in between.

Follow you around

It lives on your desktop. There's no phone app and no chat bridge to reach it from elsewhere.

Run anywhere

It needs GNOME and Thunderbird, and is tested on Ubuntu 26.04. Other distributions once someone tries them.

Install

GTK, libadwaita, Ruby and llama.cpp come from apt, Puri itself is a git clone, and the model downloads on first start. No npm, no Electron, no curl | sh.

  1. Install the packages, the model server's included.
  2. Clone Puri and install it for your user. This binds the shortcut, and AUTOSTART=1 starts Puri at login.
  3. Start the model server and leave it running. The first start downloads Qwen 3.5 4B, about 3 GB. -ngl 99 puts it on your graphics card, and -c 65536 gives it the 64K context Puri needs.
  4. Tell Puri where the model server is, in ~/.config/puri/config.toml. The README shows how.
  5. Press Super+Alt+Space.
Terminal
$ sudo apt install ruby ruby-bundler ruby-dev build-essential \
    ruby-gtk4 gir1.2-adw-1 gir1.2-shumate-1.0 libgtk-4-bin ripgrep \
    llama.cpp-tools libggml0-backend-vulkan
$ git clone https://github.com/mvysny/puri && cd puri
$ bundle config set --local path vendor/bundle
$ bundle install
$ bundle exec rake install AUTOSTART=1
$ llama-server -ngl 99 -c 65536 -hf ggml-org/Qwen3.5-4B-GGUF:Q4_K_M
# then point ~/.config/puri/config.toml at http://localhost:8080

Questions

How is this different from OpenClaw?

OpenClaw works on its own in the background: it can execute any command in your shell and browse the web, so a mail with malicious instructions in your inbox may turn it against you. Puri answers you. Everything it sends out is in the table above, a short list chosen so that such a mail can't use any of it to reach whoever wrote it, and a mail of yours leaves only when you click Send. If you looked at OpenClaw and backed off, Puri was made for you.

Where can Puri write, and what can it do to my system?

It writes only in Documents/Notes: its notes, and one file of what you asked it to remember. It reads the rest of your Documents folder and your Thunderbird mail, contacts and calendar. It has no shell, so it can't run a command, install anything or change a setting. Beyond that it plays music in Rhythmbox, and opens a mail or an event in Thunderbird for you to send or add. Your conversations are saved in ~/.local/state/puri.

Why can't it open a link?

A mail or a web page can carry instructions written for the model. Puri can't fetch a URL, run a command or send a mail, so a mail written to trick it can't make it pass your data to whoever wrote it.

Why Thunderbird?

It already holds your mail, contacts and calendar on your disk, and its compose window is the right place to check a draft before it goes.

Which model does it run?

The install above runs Qwen 3.5 4B on llama.cpp's llama-server, best on a graphics card. Any OpenAI-compatible server works, and a bigger model can run on a home server over Tailscale.
