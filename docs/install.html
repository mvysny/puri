Install Puri

A dozen short commands in Ubuntu's Terminal. At the end, Puri answers from your mail, calendar and documents, finds places and the weather, plays your music and takes dictation. Web search waits for a key of your own.

Why there's no one-line installer

Plenty of apps install with one line that downloads a script and runs it at once, curl … | bash. That script runs as you, often with sudo, before you've read a line of it, and the server can hand the pipe something other than what your browser shows you.

Puri is meant to be safe to point at your real inbox, and asking you to run code you haven't seen would be a poor start. So this guide is a dozen short commands instead of one, each one yours to read before you run it. The only sudo is apt install, and where each piece comes from is at the end.

Before you start

  • Ubuntu 26.04 with GNOME, the desktop Ubuntu installs. Other distributions haven't been tried yet.
  • Thunderbird with your mail in it, the snap Ubuntu ships or apt's.
  • A graphics card with 8 GB of memory runs the model fastest. Integrated graphics work too, more slowly. A computer with neither hasn't been tried yet.
  • About 5 GB of free disk: 3–4 GB for the model, half a gigabyte for dictation, and the rest for Puri.
  • Ubuntu's Terminal. Every command below goes there: copy a block, paste it with Ctrl+Shift+V, and press Enter. A command starting with sudo asks for your password.

Quickstart

Nine steps, each ending in a check. The model's download is the slow part, so it starts early and runs while you do the rest.

1Check Thunderbird's search

Puri searches your mail through Thunderbird's own index, which stays current only while Thunderbird's global search is on. It is, unless you switched it off: in Thunderbird, Settings → General → Enable Global Search and Indexer.

A calendar on a server, such as Google's or Nextcloud's, needs its Offline Support on, so that Thunderbird keeps a copy on your disk for Puri to read: right-click the calendar, then Properties.

Check: Thunderbird's search bar, at the top of its window, finds a mail by a word from its text.

2Install the packages

Puri's toolkit, Ruby, the model server, dictation, the office-file reader for your file index, and Rhythmbox, all from Ubuntu's archive:

Terminal
$ sudo apt install git wget ruby ruby-bundler ruby-dev build-essential \
    ruby-gtk4 gir1.2-adw-1 gir1.2-shumate-1.0 libgtk-4-bin ripgrep \
    llama.cpp-tools libggml0-backend-vulkan whisper.cpp \
    localsearch-extractor-office rhythmbox

Check: apt finishes without an error.

3Start the model

llama-server runs the model, Qwen 3.5 4B. These commands make it a service of your own, which starts whenever you log in, and start it now. The first start downloads the model, 3–4 GB, into ~/.cache/llama.cpp.

Terminal
$ mkdir -p ~/.config/systemd/user
$ cat > ~/.config/systemd/user/llama-server.service <<'EOF'
[Unit]
Description=llama-server, the model Puri talks to

[Service]
ExecStart=/usr/bin/llama-server -ngl 99 -c 65536 -hf ggml-org/Qwen3.5-4B-GGUF:Q4_K_M
Restart=on-failure

[Install]
WantedBy=default.target
EOF
$ systemctl --user daemon-reload
$ systemctl --user enable --now llama-server

-ngl 99 puts the whole model on your graphics card, and -c 65536 gives it the 64K context Puri needs. To watch the download:

Terminal
$ journalctl --user -fu llama-server

Ctrl+C stops watching, and the download carries on. Go on with the next steps meanwhile.

Check: once the log says the server is listening, http://localhost:8080 opens llama-server's own chat page in your browser, and it answers a hello.

While it runs, the model holds most of an 8 GB card's memory. Before a game, see Games.

4Start dictation

whisper-server turns your voice into text, on this computer. apt ships the server but no model, so download one, about 470 MB, then make the server a service like the model's:

Terminal
$ mkdir -p ~/.local/share/whisper
$ wget -P ~/.local/share/whisper https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
$ cat > ~/.config/systemd/user/whisper-server.service <<'EOF'
[Unit]
Description=whisper-server, Puri's dictation

[Service]
ExecStart=/usr/bin/whisper-server -m %h/.local/share/whisper/ggml-small.bin --port 8081 --inference-path /v1/audio/transcriptions -l auto
Restart=on-failure

[Install]
WantedBy=default.target
EOF
$ systemctl --user daemon-reload
$ systemctl --user enable --now whisper-server

small understands many languages, and -l auto lets it tell which one you speak. Dictation, below, has the other models.

Check: systemctl --user is-active whisper-server prints active.

5Install Puri

Puri itself is plain Ruby, cloned into ~/puri. It runs from that folder, so keep it. Bundler fetches the Ruby libraries Puri needs into the same folder, and rake install adds Puri to your desktop:

Terminal
$ cd ~
$ git clone https://github.com/mvysny/puri
$ cd puri
$ bundle config set --local path vendor/bundle
$ bundle install
$ bundle exec rake install AUTOSTART=1

rake install binds Super+Alt+Space, and AUTOSTART=1 starts Puri when you log in, so even the first press is instant. It writes three files under your home and never uses sudo.

Check: the last command lists the three files it wrote.

6Copy the config

One file says what Puri may use, and each part of it says what it does and what it sends out of your computer. Copy it, then read it:

Terminal
$ mkdir -p ~/.config/puri
$ cp ~/puri/docs/config.toml ~/.config/puri/
$ gnome-text-editor ~/.config/puri/config.toml

Everything in it is on, except web search. Places and the weather send what you ask about to public services, as the file says; to turn one off, put a # before its lines. You can also read the file here before you install.

Check: ~/puri/exe/puri opens Puri's search bar. If the config has a mistake, the terminal says what and where. Then press Ctrl+Q to quit this Puri: from now on, Super+Alt+Space starts it.

7Reindex your documents

Puri finds your documents through GNOME's own file index, the one the Files app searches. Installing the office-file reader in step 2 doesn't reread what the index already holds, even after a restart (a localsearch bug), so rebuild it once:

Terminal
$ localsearch reset

It asks before erasing the index, then reads your home folder again, office files included. That can take a while.

Check: localsearch status no longer says that data is still being indexed, and in GNOME's Settings → Search → Search Locations, your Documents folder is on.

8Try it

Press Super+Alt+Space and ask, one question per feature. When one fails, its section under Each feature says what it needs.

AskIt tries
What's on my calendar this week?the calendar
Find the last mail from someone who writes to youmail
Find the invoice from a company you paydocuments
Remember that I prefer window seatsnotes and memory
How far is it to a nearby town by car?places and routes
Will it rain tomorrow in your town?the weather
Play some artist in your Rhythmbox librarymusic
Press F5, say something, press F5 againdictation

The first answer after the model starts takes longest: the model first reads Puri's instructions, which takes up to half a minute on integrated graphics.

Check: each question gets its answer.

9Add a search key

Web search is the one feature that needs a key of your own, from Brave Search or Exa. Puri sends each search query there, and a query may quote your mail; Exa's terms let it train on what you search for. Puri reads the engine's copy of each page and never opens a link itself.

In your config, remove the # from the [search] line and the line of your engine's key, and put the key in:

[search]
brave_key = "your key"

Then make the file yours alone to read, quit Puri with Ctrl+Q, and press Super+Alt+Space: Puri reads its config when it starts.

Terminal
$ chmod 600 ~/.config/puri/config.toml

Check: asked what's in the news today, Puri shows a search step above its answer.

Each feature

What each one needs, what it sends out, and how to change it. Puri reads its config when it starts, so after an edit, quit it with Ctrl+Q and press Super+Alt+Space.

Mail, contacts and calendar

Puri reads your Thunderbird profile, snap or apt, which it finds on its own, and never writes there. A mail you ask it to write opens in Thunderbird's compose window, and an event in its import wizard; nothing leaves until you send or add it there.

Mail search needs Thunderbird's global search, and a calendar on a server its Offline Support (step 1). When Puri finds two profiles with mail, it names both: put the one you use in profile_dir under [thunderbird]. enabled = false there turns mail, contacts and calendar off.

Documents and notes

Puri searches your Documents folder, whatever your desktop's language calls it, and nothing else. It goes through GNOME's file index, which also holds the text of your PDFs and office files: localsearch-extractor-office (step 2) adds DOCX, XLSX, PPTX, ODT, ODS, ODP and EPUB, and the older DOC, XLS and PPT need nothing extra.

A file the index doesn't hold, such as a mail attachment, is converted in a container with no network when podman is installed (sudo apt install podman). Without it, Puri reads only PDFs.

Puri writes only in the Notes folder inside Documents: its notes, and Notes/PURI.md, what you asked it to remember, a plain file you can edit. To use another folder than Documents, set folder under [documents].

Places and routes

Where a place is, what's open nearby, and how far by car, from OpenStreetMap, with a map under the answer. The place you ask about goes to OpenStreetMap's public services: Photon finds it by name, Nominatim what's nearby, and FOSSGIS's OSRM the drive. Asked what's near you, Puri asks for your home address once, remembers it in Notes/PURI.md, and sends it to Nominatim. A click on a pin opens the place in GNOME Maps, or on openstreetmap.org when Maps isn't installed.

The map's tiles come from the server in tiles under [maps], OpenStreetMap's own unless you change it.

Weather

Open-Meteo's forecast, up to about two weeks ahead and in GNOME's units, for a place or for the trip in your calendar. Puri finds the place on OpenStreetMap, so the weather needs [maps] too, and sends Open-Meteo a point rounded to about a kilometre. Weather data by Open-Meteo.com, under CC BY 4.0.

Music

Puri plays an artist, an album, a song or a genre from your Rhythmbox library: "play some State Azure", or "play my favourite music" once you've told it your favourite. It starts Rhythmbox when it isn't running. An artist or a genre plays shuffled and replaces what you had queued; pause and skip with the media keys. It needs Rhythmbox's D-Bus Media Server plugin, which is on unless you switched it off.

Dictation

Press F5 or click the mic in the search bar, speak, and press F5 again. The text lands at the cursor, for you to send with Enter; Escape drops it. Your voice stays on this computer. On a processor alone, small takes some 7 seconds even for a short clip; the graphics card makes it quicker. Your desktop's own dictation types into Puri too, as into any other field.

Other models come from the same place as step 4's: base is smaller and faster and makes more mistakes, medium is slower and makes fewer. A model whose name ends in .en understands only English, and turns any other language into English gibberish. To switch, download one, put its name in place of ggml-small.bin in ~/.config/systemd/user/whisper-server.service, then:

Terminal
$ systemctl --user daemon-reload
$ systemctl --user restart whisper-server

Web search

Set up in step 9. With both keys, Puri picks an engine per query; engines = ["brave"] under [search] keeps it to one. DuckDuckGo isn't offered, because it returns no page text for Puri to read.

The shortcut

Super+Alt+Space, which GNOME leaves free. To pick another, install again with it; each rake install sets everything from its own options, so leaving out AUTOSTART=1 stops Puri starting at login.

Terminal
$ cd ~/puri
$ bundle exec rake install AUTOSTART=1 HOTKEY='<Super>p'

In Puri, Escape hides the window and Ctrl+Q quits; F9 shows your earlier conversations, and Ctrl+N starts a new one.

The model

Qwen 3.5 4B is small, a short download, and runs on most graphics cards. A smarter model needs far more memory: Choose a model compares Qwen with Ornith 1.5, says which computer runs which, and how to run the model on a home server of yours.

Games and graphics memory

While llama-server runs, the model holds most of an 8 GB graphics card's memory, so a big game may not start, or may stutter. Resources, Ubuntu's system monitor, shows how much of the card's memory is in use. Before you play, stop the model and dictation:

Terminal
$ systemctl --user stop llama-server whisper-server

Afterwards, start them again, or log out and in:

Terminal
$ systemctl --user start llama-server whisper-server

On integrated graphics the model holds ordinary memory instead, the same way.

Updating

apt updates everything but Puri along with the rest of Ubuntu. Puri updates from its folder:

Terminal
$ cd ~/puri
$ git pull
$ bundle install

Then quit Puri with Ctrl+Q and press Super+Alt+Space. A new feature may bring a new part to ~/puri/docs/config.toml: compare it with yours.

Uninstalling

This takes Puri off your desktop and stops both servers:

Terminal
$ cd ~/puri
$ bundle exec rake uninstall
$ systemctl --user disable --now llama-server whisper-server
$ rm ~/.config/systemd/user/llama-server.service ~/.config/systemd/user/whisper-server.service

What's left is yours to delete or keep:

  • ~/puri, Puri itself
  • ~/.config/puri, the config
  • ~/.local/state/puri, your conversations
  • ~/.cache/puri, Puri's copy of Thunderbird's mail index and calendar
  • ~/.cache/llama.cpp, the model
  • ~/.local/share/whisper, the dictation model
  • Notes in your Documents folder, your notes and what Puri remembered

The apt packages stay too; remove them with apt if nothing else uses them.

When something doesn't work

Super+Alt+Space does nothing

Start Puri in a terminal, where it says what's wrong: ~/puri/exe/puri. A mistake in the config is the usual one.

Puri can't reach the model

systemctl --user status llama-server says whether it runs, and journalctl --user -u llama-server why it stopped. On the first start it may still be downloading.

The first answer takes long

Before its first answer, the model reads Puri's instructions, about 10,000 tokens: up to half a minute on integrated graphics, less on a graphics card. Later questions start sooner.

Mail search finds nothing

Thunderbird's global search is off, or still indexing your mail: see step 1.

The calendar is empty

A calendar on a server needs its Offline Support on, so that Thunderbird keeps a copy on your disk: see step 1.

Office files are found by name only

The index holds them without their text: install localsearch-extractor-office and rebuild the index, step 7.

Puri found two Thunderbird profiles

Put the one you use in profile_dir under [thunderbird]: see Mail, contacts and calendar.

Dictation types nothing

systemctl --user status whisper-server says whether it runs; its model must be where the service file says, ~/.local/share/whisper/ggml-small.bin.

A game won't start

The model holds the graphics card's memory: see Games and graphics memory.

Where each piece comes from

  • From Ubuntu's archive, signed and updated by apt with the rest of Ubuntu: GTK, libadwaita, Ruby, llama.cpp, whisper.cpp, localsearch and Rhythmbox.
  • Puri, a git clone of its source: plain Ruby you can read, with nothing compiled.
  • Its Ruby libraries, from rubygems.org through Bundler. Puri's Gemfile.lock pins each one's version and SHA-256, so bundle install refuses one that changed; pikuri's libraries come from GitHub, pinned to one commit. A few compile some C on your computer, which is why apt installs build-essential.
  • The two models, from Hugging Face: the language model fetched by llama-server, the dictation model by wget. Both are weights, files of numbers that the servers read, not programs.
  • rake install writes three files under your home, a desktop entry, a D-Bus service and an autostart entry, and sets one GNOME shortcut. It prints each file, never uses sudo, and rake uninstall removes them all.
  • The two service files are the ones you wrote in steps 3 and 4.
